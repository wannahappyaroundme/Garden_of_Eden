## 📖 개요

**Garden of Eden** (Project Eden V2)은 다음을 결합한 프로덕션 준비 완료 AI 개인 멘토 시스템입니다:

- 🧠 **신경망 영감 학습**: 시간 감쇠가 있는 가중치 기반 성격 특성 시스템
- 🎯 **목표 중심 멘토십**: 방해받을 때 재유도하는 "선의의 반대"
- 🗣️ **음성 우선 경험**: STT/TTS를 활용한 자연스러운 한국어 대화
- 📚 **RAG + 웹 검색**: 의미적 기억 + 최신 정보
- 👥 **듀얼 페르소나**: Adam (소크라테스식 질문자) & Eve (격려하는 촉매제)
- 📊 **지속적 적응**: 사용자 피드백에서 역전파 스타일 학습

## ✨ 핵심 기능

### 1. **암묵지 학습** (Am-muk-ji)
- 대화 분석을 통해 성격 특성을 암묵적으로 학습
- 증거 추적이 있는 가중치 특성 (0.0-1.0)
- 시간 감쇠 메커니즘 (강화되지 않으면 특성이 희미해짐)
- 프로필 성숙도 진행 (NEW → EXPERT, 120+ 대화)

### 2. **Pitfall 감지** (선의의 반대)
- "가장 중요한 한 가지" 목표에서 벗어날 때 감지
- 정렬 점수 계산 (0.0-1.0)
- 정렬 < 0.3일 때 부드러운 경고 트리거
- 핵심 방해요소 기반 맞춤형 경고 문구

### 3. **5차원 학습 선호도 적응**
5가지 차원에서 멘토링 스타일 조정:
1. 질문 vs 답변 (소크라테스 수준)
2. 격려 vs 논리 (동기 부여 스타일)
3. 구조 vs 직관 (조직화 선호도)
4. 자율 vs 안내 (독립성 수준)
5. 성장 마인드셋 강도

### 4. **RAG** (검색 증강 생성)
- 384차원 의미적 임베딩
- 관련 과거 대화 찾기 (몇 주/몇 달 전)
- 0.5 임계값으로 상위 5개 유사도 검색
- ChromaDB 벡터 데이터베이스

### 5. **스마트 웹 검색 통합**
- 키워드 트리거 웹 검색 (신뢰도 >= 0.3)
- Tavily API (고품질) + DuckDuckGo (대체)
- 현재 이벤트/사실 쿼리 자동 감지

### 6. **목표 진행 추적**
- 시각적 마일스톤 및 하위 목표
- 기분 추적이 있는 진행 스냅샷
- AI 생성 인사이트 및 트렌드 분석
- 주간 요약 및 격려

## 🚀 빠른 시작

### 사전 요구사항
- **Python 3.12+** 및 **Flutter 3.35+**
- **API 키** (모두 무료):
  - [Google Gemini](https://aistudio.google.com/app/apikey)
  - [Groq (Whisper STT)](https://console.groq.com/keys)
  - [Tavily (선택사항)](https://tavily.com/)

### 백엔드 설정

```bash
# 저장소 클론
git clone https://github.com/yourusername/Garden_of_Eden.git
cd Garden_of_Eden/backend

# 가상 환경 생성
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt

# 환경 설정
cp .env.example .env
nano .env  # API 키 추가

# 서버 실행
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**확인:** http://localhost:8000/health

### 프론트엔드 설정

```bash
cd ../frontend

# 의존성 설치
flutter pub get

# 기기에서 실행
flutter run

# APK 빌드 (Android)
flutter build apk --release

# iOS 빌드 (Mac + Xcode 필요)
flutter build ios --release
```

- 프로필 성숙도: **NEW**
- 발견된 특성: 2-3개

## 🧬 핵심 알고리즘

### 신경망 영감 학습

**가중치 업데이트 공식:**
```python
# 시간 감쇠 (7일 후)
if 마지막_업데이트_이후_일수 > 7:
    감쇠일수 = 마지막_업데이트_이후_일수 - 7
    감쇠량 = 0.02 × 감쇠일수
    감쇠후_가중치 = max(0.3, 현재_가중치 - 감쇠량)

# 학습 (긍정적 강화)
증가량 = 0.1 × 증거강도  # 증거강도 = 0.8
새_가중치 = min(1.0, 감쇠후_가중치 + 증가량)
```

**예시:**
- 특성 "완벽주의자": 가중치 0.8
- 17일간 관찰 안됨 → 감쇠: 0.2 → 가중치: 0.6
- 새로운 증거 발견 → 증가: 0.08 → **최종 가중치: 0.68**

### Pitfall 감지

```python
# 정렬 점수 계산
정렬_점수 = llm으로_정렬_분석(사용자_메시지, 핵심_목표)

# 약한 정렬이면 경고 트리거
if 정렬_점수 < 0.3:
    # 핵심 Pitfall 트리거 매칭 확인
    if any(트리거 in 사용자_메시지 for 트리거 in pitfall_트리거들):
        경고_생성(pitfall_경고_문구들)
```

## 🌟 혁신 하이라이트

1. **역전파 스타일 멘토 적응**
   - 챗봇 시스템에서 전례 없음
   - 피드백 신호를 사용하여 5가지 학습 선호도 가중치 조정

2. **시간 감쇠가 있는 가중치 특성 시스템**
   - 인간 기억에서 영감
   - 강화되지 않으면 특성이 희미해지고, 관찰되면 강화됨

3. **선의의 반대**
   - 필요할 때 "아니오"라고 말하는 AI
   - 사용자가 목표에서 벗어날 때 도전

4. **RAG + 웹검색 듀얼 컨텍스트**
   - 의미적 기억(과거) + 최신 정보(웹) 결합
   - 대부분의 챗봇은 RAG 또는 웹검색 중 하나만 사용

5. **5차원 학습 선호도 공간**
   - 전례 없는 멘토링 스타일 개인화 가능
