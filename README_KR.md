## 프로젝트 에덴이란?

프로젝트 에덴은 단순한 챗봇이 아닙니다. **당신을 깊이 이해하고 성장시키는 AI 파트너**입니다:

- 🧠 **당신을 학습합니다** - 시간이 지날수록 암묵지(Am-muk-ji)로 당신을 이해
- 🎯 **집중하게 합니다** - "가장 중요한 한 가지"에 몰두하도록 유도
- ⚠️ **경고를 줍니다** - 목표에서 벗어날 때 "자애로운 반대(Benevolent Dissent)" 시스템 작동
- 💚 **감정적으로 지지합니다** - 힘들 때 당신을 위로하고 격려
- 🎭 **성격이 다릅니다** - 아담(논리적/아버지형), 이브(활기찬/격려형) 중 선택
- 📹 **카메라로 봅니다** - 당신이 보는 것을 함께 봄
- 🎤 **음성으로 대화합니다** - 음성 우선 인터페이스
- 🔍 **의미론적으로 기억합니다** - RAG로 전체 대화 이력 검색
- 🌐 **최신 정보 제공** - WiFi 연결 시 웹 검색으로 현재 정보 접근

**이것은 J.A.R.V.I.S입니다. Siri가 아닙니다.**

## 💡 주요 기능

### 1. 마스터 디렉티브 시스템

모든 AI 응답은 다음을 통해 필터링됩니다:
- 당신의 프로필 (가장 중요한 한 가지, 핵심 함정, 성격 특성)
- 최근 대화 기억 (최근 10개 대화)
- **의미론적 기억 (RAG)** - 전체 대화 이력에서 가장 유사한 5개 대화
- **웹 검색** - WiFi 연결 시 최신 정보
- 카메라 프레임 (시각 입력)
- 함정 탐지 및 정렬 확인
- 감정 상태 감지

### 2. 자애로운 반대

**핵심 함정**을 건드리는 질문을 하면 AI가 개입합니다:

**예시:**
```
사용자: "SLAM 알고리즘 배워볼까?"
AI (아담): "잠깐만요. SLAM은 흥미롭지만,
           지금 SNU HCI Lab이 목표 아닌가요?
           이게 당신의 '능력 함정' 패턴으로 보여요.
           에너지 분산되면 HCI 준비에서 멀어질 수 있어요."
```

### 3. 이중 페르소나

**아담 (아담)**
- 남성 목소리, 논리적, 아버지 같은 멘토
- 질문으로 생각을 유도
- 직접적이지만 따뜻함

**이브 (이브)**
- 여성 목소리, 활기찬, 격려하는 코치
- 진척을 축하하고 따뜻하게 인정
- 자연스럽게 기분 좋게 만듦

### 4. 프로필 진화

- **1주차**: 기본 프로필, AI가 질문
- **4주차**: 패턴 발견, 5-7개 특성 발견
- **12주차**: 성숙한 프로필, AI가 당신을 "깊이" 이해
- **6개월+**: J.A.R.V.I.S. 수준 파트너십

### 5. RAG (검색 증강 생성)

AI가 **전체 대화 이력**을 의미론적으로 검색:
- ChromaDB를 사용한 벡터 저장 (로컬 영속성)
- Sentence-transformers 임베딩 (384차원 벡터)
- 가장 유사한 5개 대화 검색 (코사인 유사도)
- 관련성 있을 때 몇 주/몇 달 전 대화 제공

**예시:** 2개월 전에 React에 대해 물었다면, 오늘 상태 관리에 대해 물을 때 AI가 그 맥락을 기억합니다.

### 6. 웹 검색 통합

WiFi 사용 가능하고 현재 정보가 필요할 때:
- **1차**: Tavily API (고품질 결과)
- **2차**: DuckDuckGo (항상 사용 가능)
- 스마트 트리거 감지 (키워드: "최신", "현재", "2024", "뉴스" 등)
- 상위 3개 결과를 AI 응답에 통합

**예시:** "2024년 최신 AI 트렌드는?" → 자동으로 웹 검색 트리거

## 🧠 핵심 알고리즘 설명

### 1. 암묵지 (Am-muk-ji) 학습 시스템

**개념:** 신경망 가중치 업데이트에서 영감을 받은 시스템. 대화를 통해 지속적으로 학습하고 성격 특성 가중치를 업데이트합니다.

**핵심 파라미터:**
```python
학습률 (LEARNING_RATE) = 0.1          # 강화당 가중치 증가량
감쇠율 (DECAY_RATE) = 0.02            # 하루당 감쇠량
시간 임계값 = 7일                      # 감쇠 시작 기준
최소 특성 가중치 = 0.3                 # 최소값
최대 특성 가중치 = 1.0                 # 최대값
```

**가중치 계산 공식:**

```
1단계: 시간 감쇠 적용 (특성이 최근 강화되지 않은 경우)
  만약 마지막_업데이트 > 7일:
    감쇠_일수 = 마지막_업데이트 - 7
    감쇠량 = 0.02 × 감쇠_일수
    감쇠된_가중치 = max(0.3, 현재_가중치 - 감쇠량)
  그렇지 않으면:
    감쇠된_가중치 = 현재_가중치

2단계: 학습 적용 (긍정적 강화)
  증가량 = 0.1 × 증거_강도 (고정값 0.8)
  새_가중치 = min(1.0, 감쇠된_가중치 + 증가량)
```

**예시:**
- 특성 "완벽주의자"가 17일 동안 나타나지 않음
- 감쇠: 0.02 × (17-7) = 0.2 감소
- 현재 가중치 0.8 → 0.6으로 감소
- 대화에서 완벽주의 행동 발견
- 증가: 0.1 × 0.8 = 0.08 증가
- 새 가중치: 0.6 + 0.08 = 0.68

**프로필 성숙도 계산:**
```python
NEW (신규):        < 10 대화
EMERGING (성장):  10-30 대화
MEDIUM (중간):    30-70 대화
HIGH (높음):      70-120 대화
EXPERT (전문가):  120+ 대화
```

**학습 파이프라인 (10단계):**
1. 현재 프로필 로드
2. 메시지 추출 (사용자 + AI 응답)
3. LLM 분석으로 인사이트 추출
4. 새 특성 발견 (신뢰도 > 0.6)
5. 기존 특성 강화 (가중치 업데이트)
6. 감정 상태 감지
7. 질문 패턴 업데이트
8. 목표 진화 확인
9. 시간 감쇠 적용
10. 저장 및 로깅

### 2. 함정 탐지 알고리즘

**개념:** 사용자의 요청이 "가장 중요한 한 가지" 목표에서 벗어날 때 감지. 자애로운 반대 시스템 구현.

**핵심 임계값:**
```python
정렬 임계값 (ALIGNMENT_THRESHOLD) = 0.3  # 이하면 약한 정렬
함정 신뢰도 임계값 = 0.6
```

**감지 파이프라인 (4단계):**

```
1. 사용자 메시지에서 주제 추출
   → LLM이 주제 키워드 식별

2. "가장 중요한 한 가지"와의 정렬 점수 계산
   → LLM 시맨틱 정렬 분석 (0.0 ~ 1.0)

3. 정렬이 약한지 확인
   → 정렬_점수 < 0.3인가?

4. 핵심 함정 패턴 일치 확인
   → 키워드 매칭으로 확인
```

**정렬 점수 해석:**
```
1.0         = 목표에 완벽하게 정렬 (직접 기여)
0.7 - 0.9   = 간접 지원 (관련 기술)
0.4 - 0.6   = 접선적 관련성
0.1 - 0.3   = 약한 연결
0.0         = 연결 없음

< 0.3       = 경고 트리거!
```

**경고 메시지 생성:**
- **높음** (핵심 함정 감지): "⚠️ 핵심 함정 감지: '{주제}'가 당신의 {함정_이름}과 일치합니다."
- **낮음** (약한 정렬): "'{주제}'가 목표 '{가장_중요한_한_가지}'와 약하게 정렬됩니다. 지금 필요한지 고려해보세요."

### 3. RAG (검색 증강 생성)

**개념:** 벡터 데이터베이스와 문장 임베딩을 사용한 의미론적 대화 검색.

**임베딩 모델:**
```python
모델: sentence-transformers/all-MiniLM-L6-v2
차원: 384
특징: 경량, 빠른 추론, 의미론적 유사도 최적화
```

**저장 프로세스:**
```
1. 대화에서 사용자 메시지와 AI 응답 추출

2. 결합 텍스트 생성
   → "User: {사용자_메시지} Assistant: {AI_응답}"

3. 임베딩 생성 (384차원 벡터)
   → sentence-transformers 인코딩

4. 메타데이터 준비
   → user_id, 타임스탬프, 주제 등

5. ChromaDB에 저장
   → 로컬 영속성 (backend/chroma_db/)
```

**검색 메커니즘:**
```
1. 쿼리 임베딩 생성
   → 사용자 메시지를 384차원 벡터로 변환

2. ChromaDB 검색
   → 코사인 유사도로 상위 K개 찾기

3. 거리를 유사도로 변환
   → similarity_score = 1.0 - L2_distance

4. 최소 유사도 필터링
   → similarity_score >= 0.5인 것만 유지

5. 결과 반환
   → 유사도 점수 내림차순 정렬
```

**기본 파라미터:**
```python
k (상위-K 결과) = 5              # 가장 유사한 5개 대화
min_similarity (최소 유사도) = 0.5  # 50% 이상 유사해야 함
메타데이터 텍스트 제한 = 500자
최근 대화 컨텍스트 = 10개
```

**유사도 점수 공식:**
```
similarity_score = 1.0 - L2_distance

범위: 0.0 (유사도 없음) ~ 1.0 (동일함)
임계값: 0.5 (50% 유사도 최소)
```

### 4. 웹 검색 통합

**개념:** 현재/최신 정보가 필요할 때 자동으로 웹 검색 수행.

**쿼리 감지 알고리즘:**

**키워드 가중치:**
```python
현재 정보 키워드 = ["최신", "현재", "지금", "오늘", "요즘", "최근",
                    "latest", "current", "now", "today", "recent",
                    "2024", "2025", "올해", "this year"]
  → 매칭당 +0.3

사실 정보 키워드 = ["뉴스", "소식", "가격", "날씨", "주가",
                    "news", "price", "weather", "stock"]
  → 매칭당 +0.4
```

**트리거 조건:**
```
신뢰도 계산:
  신뢰도 = Σ(현재_정보_키워드 × 0.3) + Σ(사실_키워드 × 0.4)
  신뢰도 = min(신뢰도, 1.0)  # 최대 1.0으로 제한

트리거:
  신뢰도 >= 0.3 → 웹 검색 실행
```

**예시:**
```
"최신 AI 트렌드" → "최신" 감지 → 신뢰도 = 0.3 → 트리거!
"뉴스 알려줘" → "뉴스" 감지 → 신뢰도 = 0.4 → 트리거!
"Python 배우기" → 키워드 없음 → 신뢰도 = 0.0 → 트리거 안 함
```

**Tavily vs DuckDuckGo 선택:**
```
1차 시도: Tavily API (API 키 있으면)
  → 고품질 결과, 관련도 점수 제공
  → 월 1,000회 무료

2차 대체: DuckDuckGo
  → API 키 없거나 Tavily 오류 시
  → 항상 사용 가능, 점수 없음
```

**결과 선택:**
```python
max_results = 3         # 상위 3개 결과
search_depth = "basic"  # 검색 깊이
```

**컨텍스트 포맷팅:**
```
웹 검색 결과: "{쿼리}"
(출처: Tavily/DuckDuckGo, {결과_수}개 결과)

1. {제목}
   {내용 처음 200자}...
   URL: {url}

2. {제목}
   ...
```

### 5. 마스터 디렉티브 처리 파이프라인

**개념:** 모든 서비스를 조율하여 대화를 처리하는 메인 오케스트레이터.

**완전한 파이프라인 (11단계):**

```
1. 사용자 프로필 로드
   → DynamoDB/메모리 DB에서 가져오기

2. 최근 대화 로드 (컨텍스트용)
   → 최근 10개 대화

3. RAG 의미론적 검색
   → 상위 5개 유사 대화 (최소 유사도 0.5)

4. 웹 검색 (WiFi 사용 가능하고 쿼리가 현재 정보 필요 시)
   → 트리거 조건 확인 → Tavily/DuckDuckGo 검색

5. 함정 확인 (자애로운 반대)
   → 정렬 점수 계산 → 경고 생성

6. 감정 상태 감지
   → 키워드 휴리스틱 (힘들, 불안, 걱정 등)

7. AI 응답 생성 (전체 컨텍스트 포함)
   → Gemini 2.5 Flash LLM

8. TTS 오디오 생성
   → Google TTS (아담/이브 음성)

9. 대화 저장
   → 데이터베이스에 영속화

10. RAG용 대화 임베딩
    → ChromaDB에 벡터 저장

11. 대화에서 학습 (비동기 백그라운드)
    → 특성 가중치 업데이트
```

**컨텍스트 조립 로직:**

**1. RAG 컨텍스트:**
```python
if rag_results.retrieved_conversations:
    "의미론적으로 유사한 과거 대화 {결과_수}개 발견:

    1. (유사도: 0.87) 2024-10-15
       User: React state management...
       AI: useState와 useReducer의 차이점...

    2. (유사도: 0.72) 2024-09-28
       ..."
```

**2. 웹 컨텍스트:**
```python
if wifi_available and should_search:
    "웹 검색 결과: \"{쿼리}\"
    (출처: Tavily, 3개 결과)

    1. 2024 AI 트렌드: GPT-4와 멀티모달 AI
       ...
       URL: https://..."
else:
    "웹 검색 불필요: {이유}"
```

**3. 프로필 컨텍스트:**
```python
[핵심 정체성]: 실용적 학습자
[가장 중요한 한 가지]: SNU HCI Lab 진학
[핵심 함정]: 능력 함정 (여러 방향으로 분산)
  트리거: SLAM, 로보틱스, 양자 컴퓨팅

[상위 성격 특성]:
  - perfectionist: 0.87
  - night_owl: 0.93
  - visual_learner: 0.76
```

- **프레임워크**: Flutter 3.35.7+

## 🔧 문제 해결

### 백엔드 연결 실패
**증상**: "서버에 연결할 수 없습니다"

**해결:**
1. 백엔드가 실행 중인지 확인: `curl http://3.39.177.218:8000/health`
2. WiFi/데이터 연결 확인
3. 방화벽이 포트 8000을 차단하지 않는지 확인

### 음성 인식 실패
**증상**: 말해도 텍스트로 변환되지 않음

**해결:**
1. 마이크 권한 확인 (설정 > 앱 > 프로젝트 에덴 > 권한)
2. 조용한 환경에서 명확하게 말하기
3. 한국어로 말하기 (기본 언어)

### 카메라 작동 안 함
**증상**: 검은 화면 또는 카메라 오류

**해결:**
1. 카메라 권한 확인
2. 다른 앱이 카메라를 사용 중이 아닌지 확인
3. 앱 재시작

### APK 설치 안 됨
**증상**: "앱을 설치할 수 없습니다"

**해결:**
1. "출처를 알 수 없는 앱" 허용 (설정 > 보안)
2. 이전 버전 제거 후 재설치
3. 충분한 저장 공간 확인 (최소 100MB)

## 💭 핵심 개념

**가장 중요한 한 가지:** 사용자의 단일 최우선 목표. AI는 이 목표에 집중하도록 유지합니다.

**핵심 함정:** 사용자의 주요 방해 패턴 (예: "능력 함정" - 너무 많은 방향으로 분산).

**자애로운 반대:** AI가 사용자의 "가장 중요한 한 가지"와 충돌하는 것에 대해 물을 때 경고합니다.

**암묵지 (Am-muk-ji):** 암묵적 지식. 시스템은 명시적 선언이 아닌 관찰을 통해 사용자 특성을 학습합니다.

**특성 가중치:** 성격 특성 (0.0-1.0 척도), 강화로 증가하고 없으면 감쇠합니다.

**프로필 성숙도:** 대화 수와 특성 신뢰도로 계산 (신규 → 성장 → 중간 → 높음 → 전문가).
